# 伊豆大島 釣り遠征

伊豆大島での釣行（2026/10/10〜10/12）用のガイドページです。ビルドは不要で、GitHub Pages にそのまま置けます。

## 画面（5タブ）

- **ホーム**：天気・海の状況と、潮まわり／時合い
- **釣り場**：風向きから並べ替えた釣り場と、島内の釣具屋
- **装備**：登録した装備をえらぶと、ねらえる魚（CATCH LIST）・使う仕掛け・その装備での釣果を表示
- **図鑑**：釣れた魚を記録して図鑑を埋める（全18種）
- **持ち物**：チェックリスト。自分で項目を追加・削除できます

## スキン（見た目の切り替え）

ホーム下部の **SKIN** で3種類を切り替えられます。選択は端末に保存されます。
URL で直接指定もできます（例：`?skin=nintendo`）。

| スキン | 元ネタ | 雰囲気 |
|---|---|---|
| `nature` | — | 既定。椿・海・森の自然なトーン |
| `nintendo` | [awesome-design-md](https://github.com/VoltAgent/awesome-design-md) / nintendo-2001 | ペリウィンクルの金属プレート、面取りした角、カーボンのコマンドバー |
| `dell` | 同 / dell-1996 | 黒い額縁、平たい色面、Arial Black と Times、ステッカー |

構造は `assets/base.css` が持ち、色・角丸・影・書体はすべてトークンです。`assets/skin-*.css`
がそのトークンを差し替えるので、**スキンを足すときは skin ファイルを1枚追加するだけ**です
（`index.html` の先頭スクリプトと `assets/app.js` の `SKINS` にも名前を足してください）。

## 最新情報の取得

天気・波・風向き・日の出入りは [Open-Meteo](https://open-meteo.com/) から取得しています（APIキー不要）。

- 風向きの予報から、どの港が風裏になるかを判定し、地図・釣り場の並び・トップのひとことを自動で更新します
- 日の出・日の入りは潮位グラフの「マヅメ」の時間帯にも反映されます
- 取得に失敗したときは、気象庁 週間予報（10/8 発表）をもとにした目安を表示します
- 「天気と海」の**更新**ボタンでいつでも取り直せます

潮位（満潮・干潮の時刻と潮位）は気象庁の潮位表（岡田）の値を `assets/data.js` に持っています。

## ホーム画面に追加

`site.webmanifest` と `apple-touch-icon` を置いてあります。iPhone の「ホーム画面に追加」、
Android の「アプリをインストール」で、ドット絵の魚アイコン付き・全画面で起動します。

## データの保存先

装備・釣果・持ち物リスト・スキンの選択は、各端末のブラウザ（localStorage）に保存されます。
サーバーには送信されません。別の端末へ移すときは、図鑑画面の「データの書き出し・読み込み」を使ってください。

## 構成

```
index.html            マークアップのみ
site.webmanifest      ホーム画面に追加したときの設定
assets/
  base.css            レイアウトと構造（色は持たない。すべてトークン参照）
  skin-nature.css     スキン：自然（既定）
  skin-nintendo.css   スキン：コンソール
  skin-dell.css       スキン：カタログ
  data.js             釣り方・竿・リール・魚・釣り場・潮位・持ち物の初期リスト
  core.js             共有ヘルパー、保存データ、装備の状態、ドット絵スプライト
  gear.js             装備タブと魚の詳細モーダル
  dex.js              図鑑・釣果ログ・登録フォーム・書き出し読み込み
  checklist.js        持ち物
  forecast.js         潮位グラフと時合い、天気取得、風向きの判定
  app.js              タブ、スキン切り替え、起動
  icon.svg / icon-*.png / apple-touch-icon.png
```

JS は `window.OS` という1つの名前空間を共有する普通の `<script>` です（モジュールではないので、
`file://` でローカルに開いても動きます）。読み込み順は `index.html` の末尾のとおりで、
`data.js` → `core.js` → 各機能 → `app.js` です。

アイコンは [Lucide](https://lucide.dev/)、フォントは Google Fonts を CDN から読み込んでいます。

## 公開方法（GitHub Pages）

リポジトリの Settings → Pages で、公開元のブランチとフォルダ（`/ (root)`）を指定します。
静的ファイルをそのまま配信するだけなので、この分割構成で問題ありません。

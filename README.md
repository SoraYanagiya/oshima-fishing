# 伊豆大島 釣り遠征

伊豆大島での釣行（2026/10/10〜10/12）用のガイドページです。

## 機能

- 天気・潮汐と、おすすめの時間帯
- 風向き別の釣り場と、島内の釣具屋
- 装備セレクト：竿とリールを選ぶと、狙える魚と使う仕掛けを表示
- マイ装備：持っている竿とリールを登録
- 釣果図鑑：釣れた魚を記録して図鑑を埋める（全18種）
- 持ち物チェックリスト

## データの保存先

装備・釣果・チェックリストは、各端末のブラウザ（localStorage）に保存されます。
サーバーには送信されません。別の端末へ移すときは、図鑑画面の「データの書き出し・読み込み」を使ってください。

## 構成

`index.html` 1ファイルで動く静的ページです。ビルドは不要です。
アイコンは [Lucide](https://lucide.dev/)、フォントは Google Fonts を CDN から読み込んでいます。

## 公開方法（GitHub Pages）

リポジトリの Settings → Pages で、公開元のブランチとフォルダ（`/ (root)`）を指定します。
